Детализация выкупов

План месяца — файл «План продаж 2026_Rev2.xlsx», вкладка «Доходы (продажи)», строка 5 «Сайт+розница» (значения в млн ₽; по подтверждению — план целиком относится к сайту); недельный план = план месяца ÷ 4. Недели относятся к месяцу по большинству дней. Методика: продажи = «Число продаж коррекция» (выкупы за вычетом отказов); выручка = «Итого сумма продаж коррекция»; М = выручка / себестоимость, средневзвешенно: суммарные продажи / суммарная себестоимость. Модель — столбец N «Название», категория — столбец M «Категория» вкладки «Выкупы»; в виджете М есть переключатель Модель/Категория. Дашборд считает всё из сырой таблицы «Выкупы»: в файле w44 сводные листы («Выкупы, шт./руб./М») не были пересчитаны — в них остались данные 43-й недели. Итоги сходятся с листом TOTAL: н43 — 1 002 199 ₽, н44 — 945 137 ₽.
